# Como contribuir

Abra uma **Issue** para sugerir correção ou um **Pull Request** para alterar artigos. Inclua sempre a versão SPT, build EFT e fonte que reproduza a informação.

Não inclua binários do jogo, conteúdo extraído proprietário nem cópias grandes de páginas de wiki. Conteúdo novo deve ser redigido com suas próprias palavras.

A publicação automática não garante que o conteúdo seja historicamente válido: a validação editorial é necessária.

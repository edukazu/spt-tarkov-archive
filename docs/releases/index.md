# Releases SPT

A versão de referência inicial deste arquivo é **SPT 4.1.6** (build EFT **40743**). A informação histórica deve sempre permanecer associada à build.

A verificação de releases é realizada em fontes primárias, como o [site SPT](https://sp-mod.com/) e o [repositório de releases](https://github.com/SP-Tushonka/build/releases).

> O workflow `check-releases.yml` registra atualizações potenciais como issue no GitHub; não altera automaticamente páginas históricas.
